# Проверки независимого аудита

`node tests/storage-concurrency.cjs` — пять автономных проверок сохранения и имитатора Supabase. Не использует сеть, аккаунты и пользовательский браузер.

`node tests/browser-audit.cjs` — браузерные сценарии на собственном временном localhost. Требует установленный Playwright и Chromium. Для нестандартной установки используются переменные окружения:

- `PLAYWRIGHT_MODULE` — путь к установленному модулю Playwright; по умолчанию `playwright`.
- `CHROMIUM_PATH` — путь к Chromium; при отсутствии используется браузер Playwright.
- `AUDIT_BASELINE_DIR` — распакованные исходники тега `stable-before-redesign-2026-11-19`.
- `AUDIT_FILTER` — необязательный фрагмент имени проверки.

Для сценария импорта нужны настоящие официальные PDF в `audit-evidence/live/oxford3000.pdf` и `audit-evidence/live/oxford5000.pdf`. Ссылки на них есть в `index.html` и в журнале `audit-evidence/live-comparison.json`. В ZIP приложения PDF не включены.

Логи записываются в `audit-evidence/`; браузерные данные создаются в изолированных временных контекстах. Временная дата тестов — 19 ноября 2026, календарные сценарии SRS управляют датой самостоятельно. Эти сценарии разработаны для проверки этого релиза; при запуске в другой день нужно актуализировать дату и ожидания.

Сценарий записи результата проверяет форму синтетическими данными и не подтверждает прохождение настоящего Weekly Test. `storage-concurrency.cjs` использует имитатор и не подтверждает реальную облачную синхронизацию.
